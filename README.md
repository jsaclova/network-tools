# 🍺 맥(macOS) 나만의 네트워크 진단 툴킷 (Network Tools)

맥북 및 깃허브 원격 저장소와 연동하여 어디서나 명령어 하나로 유무선 하드웨어 연결 상태, 내부 대역폭 및 주변 기기를 제어하고 날짜별 로그 아카이브를 관리하는 유닉스 표준 자동화 툴킷입니다.

---

## 🚀 원클릭 초고속 설치 가이드 (새로운 PC / 타 기기용)

새로운 PC나 포맷한 맥 환경에서 터미널을 열고 **아래 한 줄만 복사해서 엔터**를 치면, 깃허브 주소를 입력받아 `~/bin/network-tools/` 경로에 패키지 설치 및 터미널 환경 변수 매핑을 5초 만에 완료합니다.

```bash
curl -sSL https://githubusercontent.com -o /tmp/nettool_install && chmod +x /tmp/nettool_install && /tmp/nettool_install && rm -f /tmp/nettool_install
```
*(※ 신규 설치 완료 후 `source ~/.zshrc`를 치거나 터미널 창을 새로 열면 즉시 명령어가 활성화됩니다.)*

---

## 🛠️ 핵심 내장 명령어 명세 요약

터미널 작업 위치와 상관없이 어디서든 명령어 이름만 입력하면 즉시 구동됩니다.

### 1️⃣ `netinfo` - 내 장치 통합 정보 조회
* **설명**: 현재 외부 통신용 실제 인터페이스, 내부 사설 IP 주소, 10진수 서브넷 마스크, 게이트웨이, 활성 네임서버(DNS) 및 외부 인터넷 접속용 **공인 IP(Public IP)**를 지연 없이 실시간 통합 출력합니다.

### 2️⃣ `netscan` - 대역 자동 계산 주변 장치 및 포트 진단
* **인자값 없음 (`netscan`)**: 현재 물려있는 네트워크 대역(예: `192.168.55.0/24`)을 스스로 자동 분석하여 현재 살아있는 기기들의 IP 리스트를 긁어옵니다. 결과 데이터는 `log/` 폴더에 날짜/시간별 파일로 영구 보관되며, **7일이 지난 구형 로그는 시스템 보호를 위해 자동 파기**됩니다.
* **인자값 지정 (`netscan [대상IP]`)**: 뒤에 기기 주소를 붙이면(예: `netscan 192.168.55.49`), 해당 기기가 켜져 있는지 1초 만에 체크하고 웹(80, 443), SSH(22) 등 **주요 10대 포트의 개방 여부(open/closed)**를 가독성 높은 이모지 레포트로 도출합니다.

### 3️⃣ `netcheck` - 유/무선 물리 링크 정밀 점검
* **설명**: 와이파이 무선 카드뿐만 아니라, 맥북에 도킹된 USB-C 허브, 썬더볼트 독(Dock) 등 연결 상태가 유동적으로 변하는 유선 이더넷 하드웨어의 케이블 체결 상태(`Active`/`Inactive`)를 정밀 추적해 냅니다.

### 4️⃣ `netbackup` - 로컬 백업 아카이브 생성
* **설명**: 정비된 명령어 원본과 터미널 환경 설정값을 압축하여 내부 `backup/` 폴더 안에 타임스탬프 파일(`.tar.gz`)로 저장합니다. 이 `backup/` 폴더는 `.gitignore` 설정에 격리 등록되어 있어 **깃허브 관리 대상에서 완전히 제외**됩니다.

### 5️⃣ `netrestore` - 가장 최신의 아카이브 원클릭 복구
* **설명**: `backup/` 폴더 내부에 누적 보관된 아카이브 파일들 중 생성 날짜와 시간이 **가장 최신인 파일 본체를 시스템이 스스로 역추적하여 1초 만에 완벽하게 복원**합니다.

### 📖 `netman` - 터미널 통합 지침서
* **설명**: 터미널 내부에서 키보드 방향키와 스페이스바를 활용해 화면 단위로 가독성 있게 매뉴얼을 정독할 수 있는 전용 뷰어 단축 명령어입니다. (`q`를 누르면 복귀)

## 📂 저장소 디렉토리 맵
```text
~/bin/network-tools/
├── netinfo          # 통합 네트워크 요약기
├── netscan          # 자동 기기 탐색 및 10대 포트 스캐너
├── netcheck         # 유무선 하드웨어 링크 진단기
├── netbackup        # 로컬 격리형 아카이브 압축기
├── netrestore       # 최신 타임스탬프 자동 복구기
├── nettool_install  # 원격 원클릭 범용 복제 쉘
├── manual           # ANSI 인코딩 텍스트 매뉴얼 본체
├── log/             # netscan 수집 데이터 누적 보관 폴더 (7일 자동 파기)
└── backup/          # netbackup 파일 적재소 (★ Git 업로드 보안 차단)
```
